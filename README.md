# ThaiFix — ตัวต้นแบบ (v0.1)

แอปบน menu bar ของ Mac แก้ข้อความที่พิมพ์ผิดภาษาเพราะลืมสลับ ไทย/อังกฤษ

## วิธี build และใช้

1. เอา `main.swift` กับ `build.sh` ไว้ในโฟลเดอร์เดียวกัน
2. เปิด Terminal ในโฟลเดอร์นั้น แล้วรัน
   ```
   xcode-select --install     # ถ้ายังไม่เคยติดตั้ง
   bash build.sh
   open ThaiFix.app
   ```
3. ครั้งแรกจะมีหน้าต่างขอสิทธิ์ ให้ไปที่ **System Settings → Privacy & Security → Accessibility** แล้วเปิดสวิตช์ ThaiFix จากนั้นปิดแล้วเปิดแอปใหม่
4. จะเห็น `ก/A` บน menu bar ด้านบน

## ทดสอบ

- พิมพ์ `l;ylfu` ทั้งที่ตั้งใจจะพิมพ์ "สวัสดี" แล้วกด **⌥⌘L** (Option+Command+L) → กลายเป็น `สวัสดี` และคีย์บอร์ดสลับเป็นไทยให้
- พิมพ์ `ำสำ` ทั้งที่ตั้งใจพิมพ์ "ele" แล้วกด ⌥⌘L → `ele`
- ลากเลือกข้อความช่วงไหนก็ได้ แล้วกด ⌥⌘L → แปลงเฉพาะส่วนที่เลือก
- ถ้าไม่ได้เลือก แอปจะแปลงเฉพาะคำท้ายบรรทัดที่เป็นภาษาผิด เช่น `นัดกัน l;ylfu` → `นัดกัน สวัสดี`

## ข้อจำกัดของเวอร์ชันนี้

- ใช้ ⌥⌘L แทน ⌘L เพราะ ⌘L ชนกับช่อง URL ของเบราว์เซอร์
- ตารางแป้นเป็นแบบเกษมณี ปุ่มสัญลักษณ์บางตัวในแป้นไทยของ Mac อาจไม่ตรง 100% ถ้าเจอตัวไหนแปลงผิดบอกได้
- เมื่อ build ใหม่ทุกครั้ง macOS อาจถามสิทธิ์ Accessibility ใหม่ (ลบ ThaiFix ออกจากรายการแล้วเพิ่มใหม่)
- ยังไม่มีหน้าตั้งค่า, เปิดอัตโนมัติตอนบูต, ระบบ license หรือ Developer ID signing
